
# Kampüs Yaşamı

BPR201 - İnternet Tabanlı Programlama dersi kapsamında geliştirilen kampüs etkinlikleri web sitesi.

## Projenin Amacı

Üniversite öğrencilerinin kampüs etkinliklerini keşfetmesini ve etkinlik başlıklarına göre arama yapmasını sağlamak.

## Sayfalar

- **Ana Sayfa:** Proje tanıtımı ve sayfalara yönlendirme.
- **Etkinlikler:** Altı etkinlik kartı ve JavaScript ile canlı arama.
- **Hakkımızda:** Projenin amacı ve tanıtımı.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- GitHub Codespaces
- GitHub Copilot

## Çalıştırma

1. Proje klasörünü açın.
2. Terminalde aşağıdaki komutu çalıştırın:

   ```bash
   python3 -m http.server 5500
   ```

3. Tarayıcıda Codespaces Ports bölümünden 5500 portunu açın.
